# Flavor Immersed Daily（Forge 1.20.1）

生活气息与料理内容模组，包含作物、畜牧、菜品、厨具与各类工作方块。

本工作区里的核心工作方块（蒸笼、炒锅、高压锅、砧板、炸锅、变温烤箱、压榨机、坛子、茶壶、汤锅、研钵、绞肉机）
及其全部配方数据都在 [`fidworkblock`](fidworkblock/README.md)，`modid` 为 `fidworkblock`。
写工作方块配方时，直接照抄 `fidworkblock/src/main/resources/data/fidworkblock/recipe/<appliance>/` 里的现成 JSON。

发布用美术模板在 [`附属模板`](附属模板/)，含 `all.psd`、`logo.png`、`background.png`。

A Minecraft Forge 1.20.1 mod about everyday life and cooking: crops, livestock, dishes, kitchen tools
and work blocks.

The core work blocks (steamer, wok, pressure cooker, chopping board, deep fryer, temperature-controlled
oven, press, jar, teapot, soup pot, mortar, meat grinder) and all of their recipe data live in
[`fidworkblock`](fidworkblock/README.md) with `modid = fidworkblock`. Copy an existing JSON from
`fidworkblock/src/main/resources/data/fidworkblock/recipe/<appliance>/` when writing a recipe.

Release art templates are in [`附属模板`](附属模板/) (`all.psd`, `logo.png`, `background.png`).
